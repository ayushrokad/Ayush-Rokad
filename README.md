# Ayush Rokad — UI/UX & Product Designer Portfolio

A minimal, dark editorial personal portfolio website communicating professional design experience, capabilities, and verified project scope for **Ayush Rokad**, UI/UX & Product Designer based in Surat, Gujarat, India.

## Visual Direction & Tokens
- **Theme:** Dark only
- **Background:** `#111315`
- **Surface:** `#191B1E`
- **Primary Text:** `#F1F0EC`
- **Secondary Text:** `#929397`
- **Accent:** `#AFA4FF` (soft muted lavender)
- **Borders:** `#303236`
- **Typography:**
  - Display / Headlines: *Cormorant Garamond* (Serif)
  - Body / Interface: *Inter* (Sans-serif)
- **Max Content Width:** `1320px` (12-column grid desktop)

## Sections Included
1. **Header / Navigation:** Sticky bar with backdrop blur, AYUSH ROKAD® mark, anchor links, accessible mobile menu, and "Let's talk" CTA.
2. **Hero Section:** Typography-led layout with subtle animated canvas star field, headline, metadata indicators, and experience highlights.
3. **About Me:** Authentic career journey, design philosophy, and verified experience metrics (3+ years experience, 150+ mobile apps designed).
4. **Experience:** Employment timeline highlighting Letmegrab and Code Infosys.
5. **Selected Work / Highlights:** Structured project blocks based on real resume experience:
   - **01 Local Commerce Seller App (Letmegrab):** Large seller platform (~2,000+ screens/modules).
   - **02 Local Commerce Customer App (Letmegrab):** Multi-store shopping and fulfillment (~1,800+ screens/modules).
   - **03 150+ Mobile Products (Code Infosys):** Mobile interfaces, utility, tutorials, and micro-interactions.
   - **04 Confidential Banking Product:** Banking UI/UX design contributions under confidentiality.
6. **Design Skills ("What I do"):** UX flows, product feature design, mobile & web UI, design systems, prototyping, and interaction design.
7. **Toolkit:** Typography-driven pill tags for Figma, Adobe XD, Photoshop, Illustrator, Rive, Lottie, and Premiere Pro.
8. **How I Work:** Authentic working process (Understand → Structure → Design → Prototype → Collaborate → Refine).
9. **Contact & Footer:** Direct email link (`ayushrokad@gmail.com`), LinkedIn, downloadable resume PDF, and availability details.
